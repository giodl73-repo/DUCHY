# DUCHY Review Panel

DUCHY reviews govern historical title timelines, territorial lineage, source
custody, query traceability, and game-design usability.

## Active Roles

| Role | Protects | Invoke when |
|---|---|---|
| [Timeline Steward](timeline-steward.md) | Identity, spans, events, and change semantics | Changing title or continuity models |
| [Territorial Lineage Reviewer](territorial-lineage-reviewer.md) | Area-to-title movement through time | Changing parentage, containment, or lineage |
| [Source Custody Reviewer](source-custody-reviewer.md) | Citation, confidence, rights, and uncertainty | Importing or promoting historical facts |
| [Game Systems Reviewer](game-systems-reviewer.md) | CK-like utility without cloning a game | Adding game-facing concepts or fixtures |
| [Query Interface Reviewer](query-interface-reviewer.md) | Question grammar, answer shape, and traceability | Changing CLI queries or reports |

## Core Tensions

| Pulls | Against | Because |
|---|---|---|
| Timeline Steward | Territorial Lineage Reviewer | Title continuity and territorial containment can change on different dates. |
| Source Custody Reviewer | Game Systems Reviewer | Playable completeness cannot fill unsupported historical gaps. |
| Query Interface Reviewer | Source Custody Reviewer | A direct answer must still expose contested or incomplete evidence. |
| Game Systems Reviewer | Timeline Steward | Familiar strategy-game concepts can distort the historical model. |

## Review Order

1. Source Custody Reviewer establishes accepted facts.
2. Timeline Steward and Territorial Lineage Reviewer establish semantics.
3. Query Interface Reviewer proves traceable answers.
4. Game Systems Reviewer evaluates bounded design utility.

Real historical capability is blocked until source, fixture, and VTRACE evidence agree.
